# SINA App (Field Representative PWA)

Progressive Web App (PWA) built with pure HTML5, CSS3, and JavaScript for field sales representatives and procurement agents.

## Features
- **Faithful to Procurement Sketch:**
  - Auto-suggest firm name search with on-the-fly firm addition
  - Compulsory Contact Name (*), Mobile, and Address (*) fields
  - Dynamic Categories & Products with rate selection: **Per kg**, **Per piece**, **Per bag**
  - Payment modes: **Cash**, **UPI (ID/UTR)**, and **Bank Transfer (multi-image Passbook/Cheque upload)**
- **100% SVG Iconography:** Pure inline SVG icons with strictly zero emojis.
- **PWA & Mobile-First:**
  - Installable on Android, Windows, Mac, and iOS.
  - Dedicated Apple iPhone Safari installation guidance modal.
  - Offline-first cache with background sync.
- **Instant Refresh & Live Sync:**
  - Top header Refresh button with animated spin.
  - BroadcastChannel & Supabase Real-time updates.
- **Cash Float & Expenses Ledger:**
  - Starting cash float tracking, cash collections, and field expenses logging.

## Tech Stack
- Vanilla HTML5, CSS3, JavaScript (ES6)
- Supabase REST & Realtime Client
- Web App Manifest & Service Worker
